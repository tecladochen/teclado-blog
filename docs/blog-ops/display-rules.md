# 窄栏排版规范

本站正文列很窄，写作和归档时的排版判断都以这里的数字为准。阈值与
`scripts/check-post.ts` 的检查规则一一对应，改这里就要同步改脚本。

## 实际可用宽度

| 位置     | 宽度     | 每行汉字数 |
| :------- | :------- | :--------- |
| 桌面正文 | 约 520px | 约 32      |
| 移动正文 | 约 330px | 约 20      |

来源：`.prose` 的 `max-width: 65ch`（UnoCSS `presetTypography` 默认值）把正文限制在
约 520px，比 `lg` 断点下主栏实际的 762px 更窄，所以正文以 520px 为准。移动端按
`LayoutDefault.astro` 的 `min-w-390px` 减去两侧 `p-7.5` 得到 330px。

**移动端是约束方**：任何宽度判断先看 330px 下是否成立。

## 度量口径

"视觉宽度"按半宽单位计：汉字、全角标点、CJK 字符算 2，ASCII 字符算 1。
下面写"N 个汉字"时，指的是 2N 个半宽单位。度量前先去掉 Markdown 行内标记
（`**`、`` ` ``、链接语法只留可见文字）。

## 标题

主标题用 `post-title`（20px 粗体），移动端 330px 下单行放得下约 16 个汉字。

- **主标题目标 ≤ 16 个汉字**，超过 20 个汉字必须改短。英文术语占位多时主动压缩中文部分。
- **二级标题 ≤ 20 个汉字**。标题直说本节内容，不用「关于……的一些思考」这类空标题。
- 层级以 `##` 为主；同一节确有多个并列概念时才用 `###`；不使用 `####` 及更深；不跳级。
- 正文里不出现 `#`（一级标题由文章 `title` 渲染）。

## 摘要

Frontmatter 的 `description` 写 **55~120 个汉字**的完整摘要：说明文章讨论什么、覆盖
哪些内容、读者能获得什么。不复述标题，不写宣传语。它同时用于文章列表、SEO 和 RSS。

新写的摘要建议往 80~120 字走，信息量更足；下限定在 55 是因为站内已有文章都在 57~72 字，
再往上收会把每一篇都判成不合格。

## 表格

`.prose table` 已有 `display: block; overflow-x: auto`，宽表会横向滚动而不是撑破布局；
`global.css` 又给单元格设了 `min-width: 5rem`，避免窄屏下把文字挤成竖条。但滚动是兜底，
不是许可——读者仍然不愿意横向拖。

- **列数 2~3 列**。4 列是上限且需要理由，5 列必须改结构。
- **单元格宽度按列数分配**，520px 减掉每格的 padding 和边框，再允许折两行：

  | 列数 | 单元格上限   |
  | :--- | :----------- |
  | 2 列 | 约 29 个汉字 |
  | 3 列 | 约 18 个汉字 |
  | 4 列 | 约 13 个汉字 |

  表头要比正文格更短。超了就把内容移到表格下方的段落或列表。

- 单元格里不放代码块、行内 LaTeX 长公式、列表或多句话。
- 表格只用于确实需要横向比较或映射的内容。三项以上属性的对比，改成按项分组的小标题
  加要点列表，比宽表在 330px 下好读得多。

## 段落与列表

- 一段围绕一个意思，**不超过约 240 个汉字**（移动端约 12 行）。超长段落按逻辑切开。
- 列表只用于并列的步骤、条件或检查项，不把叙述性内容全部拆成列表。
- 长 URL、长英文标识符会撑宽行，写成带链接文字的形式而不是裸链接。

## 代码

`astro.config.ts` 里 `shikiConfig.wrap: true`，代码块自动换行、不横向滚动。所以
**长行会折行**，命令要主动用 `\` 断行或缩短，避免折行后读不出结构。

## 图片

- 图片与 `index.md` 放在同一个文章目录，引用写相对路径 `./name.png`。
- 文件名只用 ASCII 字符，不用中文和空格，否则链接里会变成 URL 编码。
- 宽图（架构图、多列截图）在 330px 下细节会看不清，正文里补一句文字说明。

## Frontmatter 约束

- `categories` 的每一项必须出现在 `src/.config/user.ts` 的 `categoryMap` 里。
- `series.name` 必须出现在 `seriesMap` 里。`order` 可选；若填写，需为大于 0 的整数且同专栏内唯一。
- 二者未登记时，`src/utils/index.ts` 的 `getPathFromCategory` / `getPathFromSeries`
  会回退成用中文名当 URL 路径，产生中文编码链接。新增分类或专栏必须同时改 `user.ts`。
- 文章正文文件必须叫 `index.md` 或 `index.mdx`。用别的文件名会把文件名并进 URL，
  变成 `/posts/<dir>/<filename>/` 这种两层路径。
- 目录名（即 slug）用小写英文数字加连字符，不用下划线和中文。
