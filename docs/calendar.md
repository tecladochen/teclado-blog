# 随身小日历

常驻页面外侧，不占文章布局。宽屏右侧为 132px 宽的小台历，显示图片、当天日期，以及「今年还剩多少天」「等待《罗小黑战记》第三部的天数」。窄屏收成右下角的 152px 小按钮，显示日期与今年剩余天数，展开后查看两个计数。

展开面板宽 300px，只保留当天农历、可翻月的月历，以及最近一个节日、最近一个自定义倒计时。个人事件不被节日列表挤掉；没有配置的类别不显示空栏。月历的小点标记事件，点击对应日期显示名称；「今天」回到当前月份。点击外部、收起按钮或 Escape 可关闭。

## 维护

配置位于 `src/.config/user.ts` 的 `calendarConfig`。

- `waitSince` 为等待第三部电影的起始日期，目前暂用第二部上映日 `2025-07-18`。计数为已过去的日历天数，不代表第三部的上映日。
- 「今年还剩」不包含今天；12 月 31 日显示 0 天。
- `timeZone` 使用 IANA 时区，目前按用户所在时区设置为 `America/Los_Angeles`，可改为 `Asia/Shanghai`。
- 事件有 `id`、`title`、`kind`（`holiday` / `custom`）与重复规则。
- 一次性事件：`recurrence: 'once'`，填写 `date: 'YYYY-MM-DD'`。
- 每年公历重复：`recurrence: 'solar'`，填写 `month`、`day`。
- 每年农历重复：`recurrence: 'lunar'`，填写农历 `month`、`day`；闰月不重复计入。

自定义日子在配置的 `events` 中添加，例如：

```ts
const customEvent = { id: 'birthday', title: '生日', kind: 'custom', recurrence: 'solar', month: 5, day: 20 }
```

当前不增加页面内的编辑表单，配置是唯一数据来源。

倒计时按日历天数计算，避免夏令时造成一天偏差。当日显示「今天」，一次性事件过期隐藏，重复事件转到下一次。打开页面会按当前日期重算，每分钟检查跨日，重新回到页面时立即刷新。日历中圆形底色标记今天，小点标记事件，不把节日等同于调休或放假安排。

农历使用 `solarlunar` 的历法数据，支持 1900–2100 年，不依赖网络接口或浏览器的内置农历版本。已对照香港天文台与香港劳工处发布的历法日期验证近期节日。
