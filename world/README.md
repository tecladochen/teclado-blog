# 一方田园 · 独立世界

当前阶段：概念草图 v2 的整体方向基本认可；作者指出真实性和丰满度需加强。
正式 4–5 屏布局仍在展开，未完成完整构图验收。
作者以观看、漫步和安静停留为目标，
由作者描述需求，Codex 负责美术制作工程、动态点设计和网页维护。

内容背景设为 2025 年，整体是一幅可持续扩展的横向生活长卷。
《清明上河图》仅用于说明长幅形式，内容完全按本项目需求设计。
首期重点为农村田园，各地区要素丰富、多样且协调；小镇、城市和港口
当前只保留大概方向与接续规划，后续逐步扩展。

首期确定为虚构的江南丘陵与平原交界乡村、2025 年六月上旬晴天上午。
八区交织形成约 4–5 个桌面默认视野宽度的农村长卷；
进入先看院落、菜园与田渠局部，通过拖动浏览，保留有限缩放。
首期无背景音乐或环境声。冬季、夜晚为未来可考虑的方向，本期不制作。

项目只保留一张原始风格参考：
[院落参考图](assets/art-direction/courtyard-style-study.png)。
后续场景、人物、动物和必要部件都基于这张图重新制作与调整。
旧版原稿、四姿态动画、总览图及发布图片已移出项目。

`/world/` 暂时展示这张参考图的静态预览。它含有居民、鸡和风轮，
用于表达画风与比例；它不是干净运行背景，也不是已完成的动态场景。
本次概念草图在 [源记录](assets/scene-planning/README.md)，包含八区代表线索，
不是完整 4–5 屏；完整展开与缺项核对见 [长卷布局](docs/panorama-layout.md)。
正式连续背景、独立角色、PixiJS 与 Blender 动作工程均尚未实施。
