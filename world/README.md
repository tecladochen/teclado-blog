# 一方田园 · 独立世界

当前 `/world/` 展示村落三图 v3，`/world/previous/` 展示农村长卷 v1 作对照。
两者都是静态工作稿。作者指出村落竹林割裂衔接、上下用途重复，尚未修正或验收。

2026-10-13 作者已认可新农村空间方案，并确认固定图片制作与发布路线。
本期确定只支持 PC，性能与体验先在小样验证。手机不展示入口和场景、不加载田园资源；
当前入口小屏样式仍显示，此限制尚未实现。
本轮同步并提交文档进度，不生图、改代码或重导资源。
上轮试稿与退役实现已清理并提交；新空间不沿用之前的草图。

目标是一幅可拖动、有限缩放、安静观察的横向生活长卷。首期保留完整农村八类内容、从地势与用途重新组织区域，
背景为 2025 年六月上旬晴天上午、虚构江南丘陵与平原交界乡村，首期无声。
长度由内容与协调性决定，左侧自然收尾，上下有实际用途，未来向右延伸。
各区丰富、多样，动态适度，PC 鼠标、触控板与键盘交互简洁；《清明上河图》只说明长幅形式。

## 已确认制作路线

原图工作规格 2160×720；纵向三张，上下重叠 144、左右重叠 216，有效高度 1872。
横向按内容增加统一图块；修接阶段选定唯一背景，再发布最大 1024×1024 的有效块，
每边保留 2 像素采样边缘。网页按视野加载和字节预算缓存，不保留制作的大面积重叠。
新规格、导出和加载策略尚未实施，详情见对应文档。

## 本地命令

在项目根目录运行：

```bash
pnpm world:dev
pnpm lint
pnpm build
```

`pnpm world:village` 重导村落 v3，`pnpm world:panorama` 重导对照长卷 v1。
两条导出命令会改发布图和运行清单，本轮不执行。
下一步先完成全长坐标与原图分工，再按阶段验证新原画、发布和加载方法。
具体顺序见 [制作与验收](docs/production.md)，本轮不开始实施。
