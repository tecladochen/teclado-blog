## 本轮目标与顺序

重新设计一片包含多种典型产业、完整村落与公共生活的乡村地区。
纵向三图增加的土地用于完整田块、生产后场、不同生活场所和可观察的细节。
道路、河渠、树木、墙体按用途落位，先有场所和关系，再决定连接设施。

作者要求的顺序：

1. 内容方案与实现方案一起审阅，先确定农场怎样组织、怎样快速看见结果。
2. 方案确认后出代表性的风格图，作者确认笔触、色彩、密度、尺度和构图。
3. 风格确认后先验证相邻图接续，通过后批量制作、直接接入网页与自检。
4. 作者确认完整画面效果后，再实施最终性能优化与发布整理。

当前已完成严格内容自审与多轮风格迭代，作者明确确认两张 v3 参考。下一步细化整村总平面，再验证相邻接续与完整三图高度样段。
本次风格确认不等同实际构图、接续或全村效果验收，不直接扩大为无人值守批量制作。
旧自动续做已经处于暂停状态；本轮不恢复旧任务。
农村到小镇的扩展安排退出当前生产队列，先完成这片乡村的重设计。
保留现有页面和素材供对照，不删除已有工作，不提交、推送或外部发布。

## 本轮内容范围与设计原则

作者已明确认可更大的乡村生态方向：村落、农庄、多种种植养殖、加工手艺与公共生活共同组成完整地区。
长度和篇幅不设硬上限，横向按内容需要增加；纵向三图容量继续保留。
公共生活的加入不缩减产业范围，产业也不挤掉居民日常。具体长度由环境、完整场所和观看节奏决定。
鱼塘、鸡鸭、牛羊等需要完整产业场景，田地与果园仍有规模感，但不沿用第一版的面积占比。
产业按典型性、视觉差异与关系组织，保留合理的地势、设施、季相和往来，不按单一农场的经营面积比例限制内容。

作者举例的小集市、小卖部、村委会广场表达公共生活期待，不是照抄清单。
本方案由 Codex 根据日常办事、采购、交往、休息、物资和农产品周转自主选择公共场所。
以下七片空间、产业细化、公共设施与布局为本轮提案，尚未获作者逐项确认。
当前文字方案和两张已确认 v3 风格参考已形成，尚无正式场景生产或网页变更。

保持虚构江南丘陵与平原交界、2025 年六月上旬晴天上午、斜俯视、无天空和首期无声。
产业可以包含设施、储藏、准备、当期生长与工作活动；各产业不必同时处于盛产或收获状态。
粮油加工原料来自储备；本版确定年轻单季稻、豆地播种/幼苗、生长玉米、管护果茶、暖季草菇、春茧整理和生长荷叶。
状态依据与推断边界见设计卡末尾，不把全年盛景同时画进六月。实际生成画面仍须逐处核对。

## 整体布局：七片空间共同构成乡村

左侧自然收口，生活村落完整；向右经过公共生活、园艺田作和种养场所，进入果茶与水产，最后由农务加工和外部道路连接更大地区。
这是浏览骨架，各片宽度不同，后坡产业和前方田水可以跨片延伸；七片不等同七列图片，也不画成等宽隔间。

| 片区 | 主要位置与范围 | 内容和相邻关系 |
| --- | --- | --- |
| A 生活村落 | 最左端的完整干地台地，上下都有住家生活空间 | 两组错位住宅、侧背院、共享树荫、近宅菜地和家庭小型兔养殖；右侧自然接公共村心 |
| B 公共村心 | A 右侧、村落往返与主乡路交会的干地 | 村务服务与活动小楼、树荫公共院、杂货兼投递小店、简小早餐工作面、临街可转换前场；后方保留生活住家，前方有生活菜地与公共服务后场 |
| C 园艺田作 | 村落外围和中央生产区起始，上下展开 | 育苗、蔬菜、花卉苗圃、局部旱地；前方连接稻田，后坡竹林、菌菇和桑蚕，既便于居民往来又有独立工作空间 |
| D 畜养与草料 | 中段较高干地及坡脚，前方延续田作 | 牛、羊各有完整圈舍和活动地，鸡与猪各有独立工作面，配套饲草、储料、清理与堆肥后场；前方稻田与旱地通过田口相连 |
| E 果茶坡 | 中东部较高缓坡，果树和茶行从后方深入中部 | 两种形态不同的果园、完整茶地、蜂箱与生境边缘，集中管护前场；前方逐步进入塘岸低地，生产支路连接农务区 |
| F 水产塘岸 | E 前方到更东侧的低地，水面集中成片 | 主鱼塘、小型管理塘、荷藕塘与有管理边界的养鸭浅水岸，配套塘口工作、器具和出货点；陆侧可达农务院，灌排主线绕过养殖水面 |
| G 农务加工与村口 | 最右侧较高干地，贴对外道路，靠近生产区 | 碾米、榨油、分拣、仓储、维修、装卸和农机归置；后方有材料后场，前方为可用装卸院与村口，向右仅保留未来接续条件 |

A、B 形成连续生活村落；C、D 前方的田作连成较开敞土地；E 后坡保持果茶体量；F 有完整水产环境；G 形成较集中的生产服务节点。
竹桑林下位于 B、C 后方独立高地，连接生活与副业，不横铺到全部住宅后方。
各片确需更多完整内容时增加宽度，保留作物、建筑、动物与器具共同尺度。
C 拆分为园艺工作片、竹桑林下片和主要田作片；D 拆分为牛羊草料、鸡生产点、独立猪院与收集处理后场。
这些子场所按完整内容展开，不将 C、D 各自限制在一列三图内。具体前后场和入口见设计卡。

| 莲藕等水生作物 | F 相邻荷藕塘 | 生长荷叶、新卷叶和种植疏密，与鱼塘纹理不同；不以盛花、成熟莲蓬或挖藕为主景 |
| 粮食与油料加工 | G 共用加工院 | 小型碾米、榨油工作间，原料、成品与副产物储放；以库存原料承接当前加工活动 |

这份范围保留多种典型产业，公共生活加入后不删减这些场所。
每项至少有主要生产环境、工作/管理点、储放或准备、进出关系，不能只摆一个动物、一排器具或几棵树表示产业存在。
共享的处理与周转设施集中设置，产业自身必要前场仍保留；需要更多土地就延长相应片区。

## 公共与人文生活：依据需求自主选择

### 生活村落

A 建议为两处不等规模住宅组团，初稿约 8–12 户可见住家，B 后方补少量住家；数量不是作者确认规格。
住宅有不同年代、朝向、院落开合和使用状态，共用一段村巷，保持左端建筑、院门和侧背院完整。
家务型院落可以有备餐、洗晒、盆栽、歇息；生产型家庭可有兔舍、少量家用菜园或与本户相关的器具。
屋后保留必要维护与收纳，门前有居民往来，房子不各自成为孤立的围墙小岛。

### 公共村心

本轮推荐一组尺度适中的公共节点：

| 需求 | 本方案选择 | 放置与细节 |
| --- | --- | --- |
| 办事、信息与室内公共活动 | 一栋普通村务小楼，兼有小型阅览/活动室 | B 一侧干地，入口前有停留空间，门边公告、简单自行车停放；服务后场在建筑侧后 |
| 碰面、歇脚、议事与儿童短时活动 | 老树下的公共院与小块硬地相连 | 村务楼和邻巷之间，保留穿行，局部桌凳、下棋或照看孩子的坐处，主要树冠不遮住全部场所 |
| 日常采购和包裹收取 | 一家杂货兼投递小店 | B 临街一侧，货物与包裹分区，门前少量停留与遮阴；与村巷、主乡路相连 |
| 清晨便餐与居民交往 | 一处简小早餐工作面 | 小店旁或临街住家的前间，少量桌凳、使用中的器具和收纳，形成生活节点 |
| 产品交换和临时售卖 | 一块可转换的临街前场 | 平日少量农户短时摆卖、周转、歇脚，赶集时可加摊；不预先造一整片永久市场 |
| 公共卫生与日常维护 | 小型公共服务后场、分类收集和供水点 | 建筑侧后方，清楚进出与维护位置，避开食物工作面与公共活动焦点 |

主乡路从公共节点陆侧经过，车辆在街侧停靠；公共院内部主要留给步行与停留。
摊位前场只安排几处明确位置，不堵小店、村务入口或通行。候车点可随主乡路节点设置一个简小站牌和坐处，正式规模随总平面校准。
公共院、临街前场共享相邻空间；G 的农务晒场与装卸院承担不同生产用途，不重复造多个空广场。

### 人文环境的观察线索

生活不只发生在公共中心。住家门口、村巷、竹编工作面和农务歇脚点各有居民互动。
表现新旧屋面修补、公共凳子的使用、门前电动车、自行车、包裹领取、邻里照看、短时歇息和材料交换。
桑蚕、竹编、农时准备和共同维护保留地方生活特色；日用品、苗盘、水泵、小型农机体现 2025 年。
初夏上午只选择少量正在发生的活动，同时保留收好器具、暂时空出的工作面与安静坐处，不让全村同时赶集、庆典和繁忙生产。
未自动加入独立学校、大型文化馆或其他设施；后续具体公共内容由用途和环境论证，不从作者举例推导固定清单。

上图的新增土地可以完整表现牛羊与饲草，或竹桑与菌菇；下图也可以是公共前场、工作院、荷塘与塘口，不一律铺大田或河流。
完整田作和果园仍有开敞片区，密集节点与开阔土地穿插，建筑和动物不缩小成符号。

三种典型纵向视野：

- 村落视野：后排住家和服务后场 → 村巷、公共院与小店 → 临街短时活动和生活菜地。
- 种养视野：牛羊与草料后场 → 管理、鸡猪及各自入口 → 前方田作和必要灌排。
- 水产视野：坡脚管理干地 → 鱼塘及塘口工作 → 荷塘、鸭岸与下游湿岸。

横向增加产业与生活场所数量；纵向增加一个场所的完整前后空间，并容纳相邻的不同用途。
需要更长篇幅时增宽片区或增加生产场所，不牺牲产业覆盖、公共生活或局部尺度。

## 道路：少量主线，按实际入口形成分支

- 一条主要乡路从 G 右侧对外道路进入，连接农务加工、种养与园艺的陆侧入口，到 B 村心与 A 村居；随地势、建筑和工作院改变位置，不始终居中贯穿每幅图。
- A、B 村巷服务住宅、公共院和小店，窄而有生活尺度；机动车不穿公共院中心。
- 后坡生产支路由几个必要节点分出，分别共享服务竹桑林下、畜养草料、果茶；不用每个产业另画一条完整路环。
- F 塘岸从陆侧接 G、E 的生产路，塘埂兼管理通行，不围每口塘再加宽土路。
- 田埂、行间通行和院内小径各有对应尺度，作物大块完整；转角来自入口、坡脚、田口或水线。
- G 留装卸与回车空间，货运停靠该院；B 临街留短时停靠，公共生活与重型周转的前场分开。
- 跨主渠只在必要位置设置主要桥/涵通过点，田口以小型过水设施处理，不连续重复造装饰桥。

每个分叉都登记端点、服务场所和用途。无服务对象的路删去，必要空间不足时扩大场所。
R0–R7 的具体端点、服务对象与主跨渠点 X1 已登记在设计卡；这只是文字拓扑，实际几何仍待构图核对。
道路可使用朴素硬化、细砾和土面等不同材料，公共前场、农机通路与田埂不都画成同样宽的亮土路。
围墙主要用于住家与公共边界，圈栏用于养殖，材料后场按用途设置；田野和果园不依赖密集石墙分割。

## 实现方案：缩短从出图到看见结果的距离

开发预览采用“生成原始 PNG → 登记尺寸、坐标与路径 → 页面直接显示 → 实际画面检查”的短流程。
源 PNG 与实际提示词仍保存在 `world/assets/`，开发页直接引用原始图 URL；
如页面路径需要副本，只原样复制选用文件，不重编码。具体接入在方案与风格确认后实施。

| 现在保留 | 完整效果确认后处理 |
| --- | --- |
| 最小素材清单：路径、实际宽高、世界坐标、选用状态 | WebP/其他格式与质量参数比较 |
| 原始 PNG 展示，沿用相机、PC 限制、拖动、缩放、复位和返回 | Sharp 导出、最终切块、采样边缘与资源哈希 |
| 当前检查段和相邻段的简单加载，基本失败提示与资源释放 | 分级预览、方向预取、缓存预算、弱网和长时间浏览测试 |
| 内容、画风、接边、观看尺度的实际页面检查 | 全场性能调优与最终发布资源整理 |

开发阶段按正在审阅的段落显示，避免一次解码整个长卷。
保留基本可用性与资源清理即可，不再先开发复杂缓存、编码或导出计算缓存。
已有 v2 优化代码留作后续参考，不要求本轮预览每次先跑 `world:rural`。
每张图选用后即看网页效果，小样与修订不等待完整一批编码完成。

固定全屏观看窗口；默认看全三图高度，横向拖动展开，放大有界。
原图候选仍为同一局部密度的约 2160×720、纵向三张。
如工具返回并选用的有效图确为 2160×720，无重叠高度为 2160、横向列步长为 2160；
这只是候选坐标算例，图像工具实际尺寸与清晰度须在小样核对，不先写成已确认生产规格。
不同返回尺寸不能靠不等比拉伸凑接边；尺寸策略和清晰度上限在样片阶段确定。

## 无重叠直出路线与接续验证

结论：优先试无冗余重叠的有效图，不能承诺独立生图仅靠提示词保证接边。
去掉重叠可以减少重复生成、覆盖选择和导出环节，但几何、色彩和物件比例仍需实图验证。
同一张已经连续的母图再裁切，可以保留母图内部的连续像素；
有限尺寸的整图是否承载足够局部细节、不同母图之间如何衔接，仍是独立问题。
因此不把一张压缩了细节的全农场总览当成正式底图。

1. 先锁定内容总平面和统一视觉约束：视角、比例、光向、地势、材质与生产范围。
   总平面是布局依据，不充当高细节全景。
2. 第一张代表性风格图聚焦 B/C 的公共村心与园艺交界，包含树荫院边缘、小店、邻近住家、盆苗整理和完整菜地。
   用一个视野确认细节密度与疏密，不把所有产业缩成小图标。
   风格图可用静止人物表达生活关系；正式动态主体的拆分留到后续，不阻塞风格确认。
   动物与水面造型另用 D/F 对应真实场所验证，这张图不证明全产业画风或接续已经通过。
3. 作者确认风格后，制作 2×2 相邻有效图小样，检查全部横接、竖接与四图交点。
   样片选择田园到作业面的过渡，至少包含可追踪的田埂/坡脚和一处真实通行或水线，不能仅用纯草地躲开难点。
4. 相邻生成使用已选邻图、统一底稿和明确边界位置作为参照；参考不等于生成结果必然一致。
   有效图按唯一世界位置直接相邻，不靠浏览器羽化、模糊或草树墙遮挡断缝。
5. 在网页默认全高、正常放大和逐接点检查：结构连续、无重复或截断、尺度光照一致；
   四图交点也要检查。二维小样通过后才补齐第三张高度，并进入整段生产。
6. 若无重叠相邻生成不成立，先区分页面定位与源画面问题；源画面只针对失败接点尝试一次局部连接重画。
   局部修接不重新引入固定的每图 144/216 重复带。仍不通过时暂停批量扩展，
   带实际样片重新选择生成单元或共用母稿方式，不连续增加修接图掩盖路线失败。

这一步验证的是制作路线；作者对风格的认可不能替代接续检查。
生成、参考模板、像素采样相同或构建通过都不能单独证明画面丝滑。

## 批量生产与交付检查

风格与接续小样通过后，按完整场所分批推进：
生活村落与公共村心 → 园艺田作、竹桑林下与种养 → 果茶坡与水产塘岸 → 农务加工与完整接续。
这只是生产依赖顺序，各场所边界不等同于列边界。
每批先明确功能与连接，再出图；选用图直接接入开发页，逐张记录内容和接点。

每批必须检查：

- 默认全高时主次和用途能否看懂，土地是否主要用于完整生产与生活。
- 放大后细节是否有用途，各场所是否重复，是否只是大量碎树、墙与宽土路。
- 所有新增上下、左右接边及交点是否连贯，不只检查第一屏或抽查几处。
- 道路端点、水线来去、建筑入口、田口、后场和通行是否成立。
- 网页位置、尺寸和缩放是否正确；代码改动运行 `pnpm lint` 和 `pnpm build`。
