# 页面、场景与资源架构

更新：2026-10-13。正式路线已确认，当前仍是旧静态样片实现。
本轮更新并提交文档进度，当前页面、运行清单、图片、工具与代码不变。
固定规格见 [图片制作](art-and-animation-plan.md)，预估与待测预算见 [性能](performance.md)。

## 当前入口与已实施事实

`src/pages/world.astro` 只导入 `components/WorldPage.astro`；
`src/pages/world/previous.astro` 以 `legacy` 属性选择对照长卷。
页面分别加载 `data/village-tiles-v3.json` 与 `data/panorama-v1.json`，
共享 `viewer/` 的 PixiJS 浏览与相机，博客不预加载世界素材。

- 村落原生图块组合为 2170×1773，y 起点 0、524、1048，WebP 共 2,430,344 字节。
- 对照长卷为 7200×1000，WebP 共 2,267,940 字节。
- 页面使用原图对应完整 WebP 和实时矢量遮罩；重叠仍下载、解码。
- 相机默认和最小尺度看全上下，当前村落最大源像素/CSS 像素比例为 0.75。
  支持二维拖动、滚轮、双指、方向键、复位、浏览条与观察点切换。
- 遍历全部图块清单判断视野，附近 160 世界单位预取，远离后卸载。
  尚无纹理字节缓存和请求并发队列，已启动请求不能取消。
- 当前村落静态底图直接加载三张详细图，尚无轻量分区预览；
  静态回退为现有有限图片设定，不可直接扩成全世界图片同时加载。
- 静态停留不持续绘制，合并镜头更新，后台停止待刷新；
  渲染密度上限 1.5，离开销毁，历史恢复重新初始化。
- 初始静态图、失败重试、WebGL 或脚本失败回退已实现。
  简洁 UI、生活动画与暂停尚未实现。

这些参数是当前记录，不是正式新规格已实施；约 18 MiB RGBA 是理论资源量，
不含浏览器、GPU 和画布，也不是实际 PC 性能测量。

## 本期 PC 范围（待实施）

正式页面只支持 PC 鼠标、触控板与键盘，不展示手机入口或加载手机场景。
当前 `SiteTree.astro` 的小屏分支仍显示入口，世界页面也未阻止手机初始化。
后续先落实入口隐藏与直接访问的轻量返回说明，再进入场景资源初始化；
手机不得先下载背景和 PixiJS 再隐藏画面。设备判断与断点属于实施细化，
PC 常见窗口调整仍应正常工作，不能把所有小窗口误当成手机。
现有触屏事件支持仅是旧实现事实，不作为本期适配或性能验收目标。

## 当前保留的工具

`pnpm world:village` 重导当前村落 v3；
`pnpm world:panorama` 重导对照长卷 v1，依赖 `scripts/panorama-seams.ts`。
它们仍输出原图对应发布副本和现有遮罩清单，不具备新离线去重和 1024 切块链路。
本轮不运行、修改或替换这些工具和结果。

## 正式背景发布路线（待实施）

工作原图按已确认标准在制作阶段修接，确定唯一背景；
导出工具逐块合成、裁切，输出内容不重叠、带采样边缘的 WebP。
不要求生成全长巨型文件，不把工作原图的大面积重叠保留给浏览器。
原图行列与发布块行列不同，共同坐标及源记录保持一致。
静态背景在网页上直接拼块，不继续使用大量复杂遮罩解决源图接续。

发布清单记录网格位置、有效尺寸、采样边缘、内容版本、下载字节与解码估算，
支持按行列直接定位可见块，避免镜头每次移动都扫描全部场景。
局部改图只更新受影响块，版本化路径避免旧缓存混入；
原 PNG、实际提示词和修接记录留在源目录，网页只取发布资源。

## 加载与缓存（待实施）

- 分区轻量预览先显示，只加载首视野所需预览；详细背景到达前不出现白洞。
  预览由最终背景派生，在相同位置替换，不切换构图或阻塞镜头。
- 可见块最高优先级，按前进方向预取有限邻地，快速跨区立即重排优先级。
  限制请求并发，取消未开始的过时请求；已开始的请求按能力取消或忽略结果。
- 短期保留邻地纹理，按 RGBA 估算字节而非块数管理预算，
  避免边界往返时卸载、加载反复。远离区域释放，页面离开清理全部资源。
- 将下载、解码、纹理上传和绘制分开计时，逐块安排上传，避免大量完成回调集中卡住一帧。
- 浏览器 HTTP 缓存保留文件；纹理释放与文件缓存分别管理。
  内容哈希 URL 配合缓存响应头，实际部署时核对。
- 初始 HTML 和静态回退不能同时加载全长详细块。
  保留分区静态观看与返回入口，失败块可重试，已显示内容不整屏闪换。

背景块为 1024 规格，当前视野所需数量由窗口和缩放决定。
长卷增加后总资产增加，可见纹理、更新主体和查询成本应保持局部规模；
正常网络、弱网和快速跨区的体验分别验收。

## 独立动态与运行

Astro 承载路由、元信息、回退和少量必要控制；PixiJS 管理背景块、独立主体与遮挡。
大多数静态物件留在背景，不逐件对象化，不建设经营、库存、任务或完整生产模拟。

有限动作播放器与轻量调度先在院落居民和鸡样片验证。
仅更新绘制可见与必要近邻动态，同屏活动密度随疏密控制，
场景扩展不能把全部远方角色留在更新循环。
后台、暂停和离开停止无用刷新，恢复保持统一动作时钟。
控制画布像素、高分屏开销与上传节奏，镜头刷新和动作采样分别核对。
首期无音频、季节、昼夜与天气系统。
