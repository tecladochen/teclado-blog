# 页面、场景与资源架构

更新：2026-10-13。当前是静态图块浏览，动作与完整农村新布局尚未实施。
本轮清理不改变网页图片或镜头；需求见 [需求](redesign.md)，实际完成范围见 [当前状态](design.md)。

## 当前入口与依赖

`src/pages/world.astro` 只导入 `components/WorldPage.astro`；
`src/pages/world/previous.astro` 通过 `legacy` 属性选择对照长卷。
页面分别加载 `data/village-tiles-v3.json` 与 `data/panorama-v1.json`，
共享 `viewer/` 的 PixiJS 浏览与相机。

博客只提供入口，不预加载世界素材；页面保留完整导航与 Swup 隔离。
唯一参考用于制作标准与分享图，不作为当前场景背景。
已退役运行时、失效素材清单与重建脚本在本轮清理，不再保留为需求上下文。

## 已实施的静态浏览

- 村落：3 张原生图块组合为 2170×1773，y 起点为 0、524、1048。
  WebP 合计 2,430,344 字节，全高视野需要三张。
- 对照长卷：3 张横向图组成 7200×1000，WebP 合计 2,267,940 字节。
  源图未增加像素，世界设计坐标与原图像素不是同一个单位。
- 重叠区域采用共享矢量边界遮罩；原图未变形，不以遮罩通过宣称接续已获观感验收。
- 默认及最小尺度适配完整高度；村落最大原生像素到 CSS 像素比例为 0.75。
  窗口变化只调整下限，极高窗口保持质量上限并居中。
- 支持有界二维拖动、滚轮与双指缩放、四向键、复位、浏览条与观察点切换。
  预览控件不是最终 UI 需求，简化仍待实施。
- 按二维视野加载，附近 160 世界单位内预取，远离后卸载。
  已启动请求不能取消，过时加载完成后释放，尚无通用字节缓存。
- 静态停留不持续绘制，合并镜头更新，后台停止待执行刷新；
  渲染密度上限 1.5，离开页面销毁，历史恢复时重新初始化。
- 初始静态图先显示，初始化或 WebGL 失败可重试、静态回退；
  静态模式释放绘制场景，保留横向浏览，禁用脚本仍可看图。

三张原生图的 RGBA 理论合计约 18 MiB，不含画布、浏览器与 GPU 副本。
文件体积与理论解码量不是真实手机内存或帧率测量。

## 保留的发布工具

| 命令 | 负责内容 |
| --- | --- |
| `pnpm world:village` | 用村落三张源图更新 `data/village-tiles-v3.json` 与 `public/world/village-tiles-v3/` |
| `pnpm world:panorama` | 用长卷西、中段修订、东三张源图更新 `data/panorama-v1.json` 与 `public/world/panorama-v1/` |

`scripts/panorama-seams.ts` 供长卷发布工具使用。
本轮不运行导出，不替换现有发布文件。
源目录只留实际使用的原图与对应提示词，发布目录只留当前两份清单引用的六张图。

## 后续动态方案

Astro 承载路由、元信息、回退与少量必要控制；PixiJS 组织二维图块、独立主体与遮挡。
不增加经营、任务、库存、复杂物理或完整生产模拟。
动作片段、轻量调度、暂停与源工程接口先在局部样片验证。

背景连续，发布可按观察区域切块；大多数静态器物不逐件对象化。
新增图块保持局部精度，共同布局与观看尺度见 [布局](panorama-layout.md)。
起始视野与邻近区域优先加载，快速移动时降低或取消过时请求；
远离后释放解码资源，缓存按估算字节控制，不只按图片数量限制。

只更新可见动态，后台、暂停与离开停止无用刷新；恢复时保持一致动作时钟。
控制画布像素与高分屏开销，区分镜头刷新和动作采样。
首期无音频、季节切换、昼夜时钟与天气系统。

## 发布资源约定与试验预算

源工程、部件与原始动作帧保存在美术源目录；
`public/world/` 只放发布副本，使用内容版本路径。
背景与透明动作分别比较 WebP 编码、下载与解码，
检查轮廓、细线和透明边缘，避免全世界巨型图集。
清单记录共同坐标、图片规格、锚点、时长及必要步幅；
局部修改应仅重导相关素材，正式工具的增量能力仍待验证。

| 指标 | Codex 的试验目标，尚非已测结果 |
| --- | --- |
| 首屏图片与动作下载 | 约 2–4 MiB，其余按探索加载 |
| 移动端常驻解码素材 | 先按 64–96 MiB 验证，画布、GPU 与浏览器开销另计 |
| 流畅度 | 桌面接近 60 帧/秒，目标手机稳定 30 帧/秒 |
| 长时间探索 | 往返跨区后缓存稳定、内存不持续增长 |

这些数值是工程试验参数，不能替代清晰度、作者观感或真实手机验证。
按阶段检查桌面、真实手机、弱网、拖动缩放、暂停、后台和反复进入；
窄屏窗口只验证布局。

技术资料：[PixiJS](https://pixijs.com/8.x/guides/getting-started/intro)、
[Canvas 优化](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)。
