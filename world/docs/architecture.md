# 页面、场景与资源架构

更新：2026-10-13。以下描述仍在运行的旧 v2 实现，不是本轮新预览的固定架构。
作者要求新开发流程直接预览原始 PNG，暂缓 Sharp、WebP、复杂导出与缓存优化；
方案见 [农场重设计 v3](farm-redesign-v3.md)，尚未实施。
旧代码保留，供效果确认后的最终优化参考；基本 PC 支持、相机与资源清理仍保留。

## 页面与 PC 范围

`src/pages/world.astro` 导入 `components/TiledWorldPage.astro`，使用 `data/rural-v2.json`。
`src/pages/world/previous.astro` 保留 `WorldPage.astro` 与 `panorama-v1.json` 对照。
独立世界不使用博客布局，博客不预加载田园素材，入口保留完整导航和 Swup 忽略规则。

`viewer/platform.ts` 在博客入口与两个世界页共用。手机 UA、桌面 UA 的 iPad 与纯触屏设备
不进入场景；窄 PC 窗口、带鼠标的触屏笔记本仍可使用。手机直接访问只显示轻量返回说明。
主入口初始 HTML 不挂载场景图片，对照页图片只有数据地址；设备通过后才设置 `src`，PC 的首视野预览先开始下载，再动态导入 PixiJS 浏览模块。
禁用 JavaScript 时只显示返回说明，不下载场景。真实设备网络行为另做检查。

## 当前背景发布

九张基础PNG按2160×720裁去额外边缘，保持原生物件密度。
`prepare-rural.ts` 根据recipe合成任意列数，再应用经过实际检查的局部修接，导出唯一像素背景。
基础原画不拉伸，局部修接的微小框幅校正另记；不模糊或透明度叠化。
当前导出使用内存工作atlas，本地QA可写整幅PNG；浏览器只加载发布网格，不加载atlas。

当前首段有效范围6048×1872。详细图按1024内容网格输出，底行高848、最右列宽928，
每边 2 像素采样邻域不扩大世界尺寸。WebP 详细图质量 88，预览按 2048 源像素分区、
宽度最多 640、质量 65；这些编码值是实施参数。文件名含内容哈希，清单记录实际下载字节与 RGBA 估算。
`assets/rural-v2/export.json` 保留源哈希、裁边和选边；浏览器不读取源 PNG 或大面积制作重叠。
同内容发布块保持相同哈希URL；当前导出重新计算编码，超长导出的计算缓存待实现。

## 已实施加载与缓存

- `visibleTileIds` 按网格范围直接查询可见和邻近块，不逐帧扫描全长清单。
- 同位置低清预览垫底；按有序分区二分查询，只挂载并保留邻近预览图片，可见详细块优先。
- 方向预取前方 1024、后方 256 世界像素，额外近邻带 160。
- 两路详细图请求；镜头移动重排尚未开始的队列，过时的在途结果忽略并释放。
  PixiJS 已开始的下载不宣称可物理取消，响应和解码仍可能发生。
- 每个镜头刷新帧至多加入一张已返回纹理，避免同帧集中加入；不宣称能独立控制浏览器内部解码时间。
- `ByteCache` 按详细图 RGBA 估算管理 96 MiB 近期纹理，命中更新近期顺序；
  可见纹理受保护，超宽视野必要时允许超过此试验预算，不能删掉应显示的内容。
- 卸载和重载串行处理，减少区域往返及历史恢复的资源竞争；HTTP 文件缓存与纹理缓存分别管理。
- 画布设备像素密度上限 1.5，最大画面尺度 0.75；静态停留不持续绘制，后台停刷新，离开销毁。
- WebGL 初始化失败或上下文丢失保留可拖动缩放的分区预览；失败详细块显示局部重试。
  渲染模块导入失败保留可横向滚动的预览。相机默认与最小尺度看全上下。

首次预览也有传输时间，不承诺即时清楚或弱网没有等待。
当前详细清单在初始化时建立全量位置索引，预览只保留局部节点；后续超长内容仍需检查元数据启动成本，
必要时改为分段清单。内容哈希 URL 的实际 HTTP 缓存响应头在部署时核对。

## 保留版本

旧村落 v3 保留为替换前检查点，不由主入口加载；旧长卷 v1 的对照仍使用完整原图 WebP、
实时矢量遮罩和旧加载方式。旧命令 `world:village`、`world:panorama` 只维护保留版本，
不能用旧资源成本或检查结果证明新路线合格。
新命令 `world:rural` 重导当前任意列数场景；`world:proof` 只恢复被否决的历史两列对照。

## 独立动态与验证

后续 PixiJS 加入独立主体与必要遮挡，大多数静态物件留在背景。
只更新可见与必要近邻主体，不建设经营、库存、任务或完整生产模拟。
有限动作播放器、可编辑源工程与统一时钟先在院落居民和鸡样片验证，首期无音频、季节和天气系统。

页面数据属性提供加载块数、理论解码字节、队列数与渲染调用 CPU 耗时供自检，
CPU 渲染耗时不等于显示帧率、GPU 时间或浏览器总内存。
小样工程检查不能代替真实 PC、弱网、长卷缓存与作者视觉验收，门槛见 [性能](performance.md)。
