# 农村长卷布局与观看尺度

更新：2026-10-13。这是后续重新设计的约束，不是当前图片已实现的说明。
当前网页保持原样，图片制作暂停；实际版本见 [当前状态](design.md)。

## 空间原则

- 八区交织在同一片土地上，横向长度由完整场所、联系和疏密决定。
  不规定屏数、长宽比、等宽段落或母稿数量。
- 左侧村落是本期起点：核心住宅、院门、侧背院与通路完整，外围通过林缘、
  缓坡、草地和路径自然收口。右侧保留未来小镇的道路与地势接续。
- 上下明显增加实际土地和用途，各段分别展开屋后通路、林坡、田口、岸路与服务空间。
  不通过拉高原图、填空色带、重复林草或同类建筑证明纵向扩展。
- 扩大空间保持局部物件像素密度，通过新增相邻原图承载新增土地；
  不把更多内容压进同像素预算的整高图。
- 整体用途、视角、物件比例、光向、道路水系与邻接位置先统一，再划分制作图块。
  图片边界不决定场所边界。

## 村落重新设计的约束

作者指出当前 v3 竹林横贯衔接，上下院落、菜园和棚内器物重复。
作者随后明确要求重新设计，不用之前草图。
因此以下只规定需要成立的空间关系，不预设旧草图里的房屋数量或竹林坐标：

- 竹林形成一片独立地块，有合理地势、服务通路与林缘；不能横插在住宅联系中间。
  编作需要明亮操作面，菌菇需要适当遮荫，设施用途与形态各有区别。
- 住宅错位、院落有差异，洗晾、备餐、休息与工具收纳按实际住家用途组织。
  不重复整套“房屋＋菜园＋棚＋同类陈设”。
- 生活巷道通到院门，公共空地、供排水与农务路形成合理联系。
  连通和疏朗空间也有价值，不把每个空隙填成工作棚。
- 近宅菜园集中承担种菜和育苗，各住家不再复制完整菜园；大田与近宅小菜畦用途区分。
- 田渠、田口、开敞草岸和林坡提供与住家不同的场景体验。
  通过地势、通路和用途过渡，不能靠横向植被墙隐藏接缝。
- 左端核心房屋完整可读，外围自然收口；浏览时镜头可以裁切建筑，
  世界边界本身不能截断重点村居。

具体竹林位于哪一侧、住宅有几户、公共农务点如何分布，由重新设计决定。
此前“右上竹林”“固定三排”等安排不作为作者确认条件。
当前图片只用于指出问题，不能把保留它们理解为认可其布局。

## 观看尺度

固定全屏窗口，缩放改变画卷的显示比例与可见范围。
默认从看全上下进入，横向长卷通过拖动浏览；不按整幅宽度缩小到一屏。

| 状态 | 规则 |
| --- | --- |
| 最小及默认 | 按有效窗口高度与世界高度适配，刚好看全上下，到此停止缩小 |
| 放大中 | 看更小的局部，允许有边界的上下和左右平移 |
| 最大 | 按源图实际精度与清晰度校准，达到上限后停止放大 |
| 窗口变化 | 重算高度适配下限，保持清晰度上限；异常大窗口必要时居中显示 |

最大观察尺度由 Codex 重新设定，作者验收效果。
不从旧百分比、截图、坐标或人物屏幕像素数推导新硬约束。
`100%` 可以表示校准后的上限，百分比只是显示方式。
人物、建筑与器具共用比例，不逐件缩放来满足某个初始数值。

默认视野要理解各处用途；最大视野可观察器具和人物动作，
不追求手指、细微表情或房屋内部。手机显示同一长卷的局部，
缩小边界同样看全上下，放大后观察细节。
以桌面、窄屏和真实触屏核对实际可读性，检查窗口不限制世界长宽比。

## 原画与拼合

相邻原图保留重叠地形，共享道路、水系、坡脚与物件比例。
检查完整拼合图，再检查默认与最大视野；不能只看每张局部插画。
保护屋顶、围栏和工作点完整轮廓，接缝不以模糊、透明渐变或植被堆叠掩盖。
源图精度不足时补制作或校准上限，不通过放大、锐化宣称细节已恢复。

制作图块和发布瓦片可以不同；资源加载范围按观察和设备成本规划。
新增长度与高度的下载、解码和手机表现重新测量，旧长卷数据不能代替。
当前 v3 的尺寸、重叠宽度与最大倍率是实现记录，见 [架构](architecture.md)，不限定新设计。

## 验收重点

完整左端、明显纵向用途、独立竹林、不重复的场所、连通道路水系、
合理灌排与初夏季相、统一比例光照，以及默认和最大尺度的清晰度一起检查。
生成完成、遮罩选择或工程通过不能替代作者的完整图观感验收。
