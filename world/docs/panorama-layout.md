## 空间与图块的关系

从地势、生活中心、生产关系和观看路径组织完整农村，八类内容交织，不固定八块独立场景。
后方缓坡、左侧居住台地、中央耕地和右侧塘岸形成共同土地。
村落左端完整自然收口；竹林在住宅组团右后方独立成片，留坡脚空地和支路；
中央田野最开敞，塘岸舒缓，村口在干地重新聚集并向右接续。

纵向固定三张标准原图，共同形成完整有效高度；横向列数由内容与疏密决定，不限屏数。
各场所占据不同数量的统一图块，不使用不同原图尺寸，不把三张画成三个独立横条。
功能区、地势和建筑可以跨图块，图片边界不能迫使道路变直或住宅全部搬到图块中心。

先登记完整场所、道路水系、建筑轮廓和接续位置，再安排重叠带内的边界。
保护完整屋顶、院门、桥和工作面；遮住接缝不代表接续已经合格。
当前小样未通过审核，后续先核对位置、裁边、重叠和覆盖，再逐处检查实际拼合，按问题确定处理方式。
新增空间按固定局部像素密度制作，不拉伸原图、不在同像素预算整高图中缩小所有对象。

## 观看规则

固定全屏窗口，缩放改变画卷显示比例与可见范围。
默认从村居生活焦点进入，看全上下；整幅横向宽度通过拖动展开，不压缩到一屏。

| 状态 | 规则 |
| --- | --- |
| 最小及默认 | 有效窗口高度除以完整世界高度，到刚好看全上下后停止缩小 |
| 放大中 | 观察局部，允许有界上下、左右平移 |
| 最大 | 按新源图实际清晰度校准，达到上限停止 |
| 窗口变化 | 重算高度适配下限，保留清晰度上限；异常大窗口必要时居中 |

人物、建筑与器具共用比例，默认能理解地区用途，放大可看器具和生活动作；
不追求手指、细微表情或屋内细节，不逐件放缩来满足旧物件标尺。
本期只验证 PC 常见窗口、鼠标与触控板操作，不设计手机或触屏观看。
PC 调整窗口仍保持观看规则；手机不展示或初始化场景，设备限制已实现，真实手机网络检查待补。
旧百分比、截图尺度和旧世界坐标不决定新镜头。`100%` 仅可表示校准后的上限。

## 连续性与加载体验

源稿的重叠用于修接；最终背景的每个位置只选定一份像素，
再导出最大 1024×1024 的发布块，细节和源稿坐标保持一致。
发布块在不同源稿边界处也必须接边一致，采样边缘不重复放置世界内容。

当前视野的背景块优先，邻近和前进方向提前加载。
详细块未到时显示同位置的分区预览底图，拖动缩放仍有效，避免白洞和整屏闪换。
快速跨区允许暂时只见预览，但不能让旧区域请求阻塞新视野。
当前主页面已实施这些加载与缓存措施，体验验收尚未完成，成本与证据见 [性能](performance.md)。

## 验收

- 完整村落起点、独立竹林、不同用途和充足纵向土地成立。
- 道路接实际入口，水系遵循地势；八类内容齐全且有疏密。
- 拼合与发布块无明显断路、重复器物、切断屋顶、比例或光照突变。
- 默认看全上下、局部可读、放大上限清楚、二维浏览自然。
- 普通浏览不反复出现白洞或加载阻塞，快速跨区有连续预览和优先级恢复。
- 当前性能检查推迟至多组场景形成后；届时 PC 实际电脑、弱网、后台和往返分别记录，手机只验证不进入场景。

规格和方案确认是制作基线，不是原画、动作或设备性能已经合格。
