更新：2026-10-13。本文件只记录当前有效需求。
实际完成情况见 [当前状态](design.md)，被替代条件与来源见 [需求变更](decisions.md)。

## 当前任务

作者已确认新农村二维空间及固定图片制作、重叠、发布规格。
本期只支持 PC，不展示手机入口或场景。先保证 PC 性能与体验，避免成品难用和卡顿。
本轮同步该范围、明确验收并提交进度；不生图、改代码、裁切图片或重导资源。
当前两个网页和图片保持原样，手机限制作为待实现项记录。

后续按 [新农村空间](rural-scenes.md)制作，不沿用之前的草图。竹林在住宅组团右后方独立成片，
不能横贯住宅联系与图块衔接。新增上下空间要产生不同用途和更完整的生活关系，
不能重复院落、菜园、棚子及棚内陈设来填满空间。
当前 v3 留作可浏览进度，不能视为已通过验收。

## 观看目标

访客进入一片连续、统一、内容丰富的手绘生活世界，可以拖动、有限缩放和安静停留。
以观看为主，交互简单直觉，无需经营、安排生产、完成任务或承担离开的损失。
动态用于让画面有活性，整体协调比动作数量与表现强度更重要。

作者描述需求并验收效果，Codex 负责设计、制作工程、自检和返工。
《清明上河图》仅说明横向长幅形式，不参考其时代、内容或叙事安排。
产业和生活线索用于组织可信场所，不自动转成库存、产量、离线结算或完整劳动模拟。

## 已确认的条件

| 项目 | 当前有效要求 |
| --- | --- |
| 画风 | 唯一院落参考的笔触、色彩、比例、斜俯视视角与光照；参考原图保持不变 |
| 背景 | 2025 年，虚构江南丘陵与平原交界乡村，六月上旬晴天上午 |
| 首期 | 完整农村田园八类内容，基于地势与生活重新组织区域，丰富多样且联系合理 |
| 长卷 | 同一片土地横向连续展开，长度随内容和疏密决定，不设屏数上限 |
| 左侧 | 村落核心住宅与院落完整，外围自然过渡到画面边界 |
| 上下 | 明显增加实际土地、场所与通路，各段按用途设计，保持局部细节密度 |
| 竹林与重复 | 竹林独立成区；新增空间不能简单复制住宅、菜园、棚及器物组合 |
| 窗口 | 固定全屏观看窗口；默认及缩小下限刚好看全上下，横向继续拖动浏览 |
| 放大 | 上限按素材清晰度校准，超过上限停止；放大后可有界二维拖动 |
| 素材方式 | 统一原图规格，固定纵向三图及重叠，离线修接去重后切块发布，见 [制作标准](art-and-animation-plan.md) |
| 交互与 UI | PC 鼠标、触控板拖动缩放与键盘控制直觉；去掉常驻提示、下拉框和多余控制 |
| 支持范围 | 本期仅 PC 浏览器；手机不展示入口与场景，不初始化或下载田园资源 |
| 动态 | 安静、有活性、有停顿；不是所有内容都动，也不要求每个动作都复杂 |
| 声音 | 首期无背景音乐与环境声 |
| 后续扩展 | 向右自然衔接小镇、城市、港口，当前只作大概规划 |
| 冬季与夜晚 | 未来设想，本期不制作素材或切换系统 |
| 维护 | 独立 `world/` 模块，由 Codex 维护源工程与发布工具 |

当前网页仍有下拉框、浏览条和说明面板，这是预览实现与已确认简洁 UI 目标的差距。
本轮保留现状，不把这些控件补写成需求。暂停控制在动态场景实施时再接入。
本期不制作手机观看、触屏交互与手机性能方案。PC 的常见窗口大小和缩放仍需正常工作。
当前 `src/components/SiteTree.astro` 在小屏将入口改为相对定位并继续显示，
`/world/` 也未限制手机初始化；这与最新 PC 范围不一致，后续实施须修正，不能称已关闭。
手机直接访问只保留返回博客等轻量说明，不加载场景；具体判定在实施中细化。

## 内容基线与设计自由

作者认可新空间方案并保留八类内容：村居院落、近宅菜园育苗、稻田旱豆与田渠、果茶坡与蜂箱、
竹木菌菇与编作、鱼塘荷岸与鸭水、畜禽草料、共用农务与村口。
它们从地势、生活中心、生产和通行关系重新组织，不强制八块独立区域，
也不由图片分块决定功能边界。已确认布局和通行灌排见 [农村规划](rural-scenes.md)。

[场景设计](rural-scenes.md)的整体空间已确认；具体作物、器具、居民数量、
节点数量和精确物件坐标仍由 Codex 细化，须符合时代、季相与真实用途。
作者举例的店铺、工厂、图书馆、海洋馆、办公楼、机场、码头不构成本期必做清单。
土地、水面、路边空地与林缘承担疏密和连接，也需要完整设计。

原图尺寸、纵向数量、重叠及去重发布规格已获得作者确认，固定执行。
横向列数按内容需要确定；精确物件坐标、屏幕标尺、编码质量、动作工具、
请求调度、帧率与资源预算仍是实施细化或试验参数，不是已验证结果。
在核心目标内由 Codex 校准，不能用缩小物件、删除特色或复制素材降低制作成本。

## 验收口径

| 范围 | 通过条件 |
| --- | --- |
| 整体空间 | 八类内容用途可辨，土地、道路、水系和地势连贯；左侧完整、自然收尾，上下用途充分 |
| 丰富性与真实性 | 各处用途和组合不同，作物季相、设施、通行与灌排可信；静止时也有内容可看 |
| 观看 | 默认看全上下，最小处停止缩小，最大处清楚；局部可读，拖动缩放直觉 |
| 拼合 | 接续、建筑轮廓、地形、比例与光照一致；不以遮罩通过代替完整图的观感检查 |
| 动态 | 主体接地、接触与遮挡可信，正常速度无明显滑步、闪烁或重影，启停与节奏自然 |
| 界面 | 画面为主，少量必要控制；预览辅助控件不成为最终常驻界面 |
| 运行 | PC 检查首次加载、连续拖动缩放、跨区往返、暂停、后台和反复进入；无明显卡顿、持续白洞或内存增长 |
| 手机限制 | 入口隐藏，直接访问不初始化场景、不下载田园图和渲染代码 |

阶段顺序与交付方式见 [制作与验收](production.md)。图片生成、代码构建、
