# 需求与边界

更新：2026-10-13。首期方案 v1 已定稿，已进入总构图制作，网页运行方案尚未实施。
实际状态见 [当前状态](design.md)。

## 观看目标

一幅可以漫游、适度缩放和安静停留的二维横向生活长卷，时间背景设为 2025 年。
作者描述需求，Codex 维护制作工程，并主动设计动态点和整体节奏。
访客以看为主，进入后无需经营、安排生产、完成任务或承担离开的损失。

《清明上河图》仅用于说明长幅形式，不参考其内容、时代、产业、场景顺序或叙事。
本项目内容完全按作者自身需求设计。地域已确定为虚构的江南丘陵与平原交界乡村，
首期画面固定为 2025 年六月上旬晴天上午，光向沿用唯一参考图。
不把此前提出的 2010 年代河口生活圈等建议当作已确定要求。

首期重点为农村田园。后续向小镇、城市、港口等方向自然扩展，
这些部分当前只保留大概设计和接续关系；店铺、工厂、图书馆、海洋馆、
办公楼、机场和码头均为作者举例，不构成必须全部制作的清单。

画面要有动态感，但不要求所有内容都动，也不要求每个动作都显眼或复杂。
整体协调、空间可信和安静的生活感优先于动作数量与表现强度。
居民主要在各自场所活动，偶尔短距离移动。

| 项目 | 要求 |
| --- | --- |
| 美术基准 | 只使用保留的院落风格参考；后续全部据此重做与调整 |
| 时代 | 2025 年，整幅的服装、交通、设施与生活方式保持同一时代 |
| 地域与时段 | 江南丘陵与平原交界的虚构乡村，六月上旬晴天上午 |
| 形式 | 横向连续长幅，内容由本项目需求独立设计 |
| 本期范围 | 农村田园；后续地区暂作大概规划 |
| 长卷范围 | 完整八区约 4–5 个桌面默认视野宽度，不是八个独立页面 |
| 内容核心 | 各地区要素丰富、多样，有自身特点与合理的生活、产业联系 |
| 空间 | 连续土地，院落、小径、田埂、水岸与各区域自然衔接 |
| 视角 | 固定斜俯视，比例、透视、光照统一 |
| 镜头 | 局部细节优先；从院落、菜园与田渠起始，拖动平移、有限缩放、自然边界 |
| 动态 | 静态主体、轻微环境活动、间歇生活动作和少量偶发活动协调组合 |
| 居民 | 场所内生活动作优先，短距离走动按需要制作 |
| 交互 | 以观看为主；未来仅保留返回、复位、暂停等必要控制 |
| 声音 | 首期无背景音乐和环境声 |
| 季节扩展 | 冬季、夜晚记录为未来设想，本期只做固定初夏上午 |
| 可达性 | 未来支持键盘、读屏说明和减少动态偏好 |
| 维护 | 独立 `world/` 模块；由 Codex 维护源工程和发布工具 |

首期农村已有内容线索：稻作、蔬菜育苗、豆作、果品、茶作、鱼鸭、荷莲、
草料畜禽、蜂群、段木菌菇、竹木编作，以及共同生活。
这些线索用于统筹农村部分的丰富性，不作为整幅未来长卷的全部内容边界。
产业关系用于组织土地、建筑、器物和活动的合理联系，不自动增加库存、
产量、离线结算或完整劳动模拟。

旧版的世界像素、六位居民等数量和机具预算属于历史设计数据，
不作为新美术分辨率或活动密度的硬约束。

## 首期内容设计原则

- 各区具有不同的土地、水系、植物、生产、建筑、器物与生活活动组合，
  形成可辨认的区域特点，不让所有地方都成为同一类田块或房屋。
- 内容既有产业，也有日常生活与必要设施。2025 年的乡村可以呈现瓦房院落
  与现代生活、交通和生产设施共存；具体对象先列候选，再结合布局取舍。
- 丰富性来自不同用途、材料、环境与生活细节，不要求每一处都密集。
  农田、水面、林地和路边空地同样是正式内容，承担空间疏密与自然衔接。
- 先规划农村各区的位置、特色、产业协作及空间疏密，再设计具体动态点。
  动画适度、整体协调，静止观看时也有丰富内容可观察。
- 首期之外只明确延伸方向、道路或水系等接续条件，不提前细化完整城镇和城市美术。

## 内容与观看基线

作者已同意沿八区建议继续细化：村居院落、近宅菜园育苗、稻田旱豆与田渠、
果茶坡与蜂箱、竹木菌菇与编作、鱼塘荷岸与鸭水、畜禽草料、共用农务与村口。
各区穿插成连续乡村，详细构图、生活片段和连接见 [农村场景方案](rural-scenes.md)。
以院落生活、林坡工作和村口服务为三处停留节点，
通过大田、水面、林缘和道路拉开疏密。完整农村是首期交付范围。
八区主题清单不等于完整构图；当前概念草图的空间规模和场所内容尚未做足。
正式长卷的观看段落、缺项与真实性修正见 [长卷展开](panorama-layout.md)。

默认尺度能看清居民正在做什么、地区怎样使用，近看可辨小器具；
不追求看清人物手指、细微表情或进入房屋内部。
约 4–5 屏以普通桌面宽屏的默认观察尺度为口径，
实际世界坐标和美术像素尺寸在总构图与观察尺度验证中确定。
手机竖屏观察同一长卷的局部，横向拖动浏览；横屏可看更宽范围，
不为展示全景把主体缩小到不可读。

动态优先由院落居民与鸡、局部渠水、少量鸭活动和村口间歇分拣承担。
其他区域以静态内容和生活痕迹为基础，按整体观感选择少量补充动作。
不因八区齐全而要求八处人物持续劳动，也不增加循环交通与完整生产模拟。

## 固定内容与制作细化的边界

v1 固定观看目标、唯一画风、时代地域时段、八区范围、空间组织、
动静原则、首期无声、交付阶段和验收口径。
角色数量、具体作物品种与器具、精确坐标、图片尺寸、图块划分、
关键帧与采样参数由 Codex 在制作中细化，不要求作者逐项指定。
这些选择应符合已定季相、空间与资源目标；不得通过取消区域特色来降低制作成本。
核心画风、观看尺度目标、地区用途或首期范围发生变化时，再回到方案讨论。

冬季、夜晚只记录为未来方向。本期保存布局、角色设定与可编辑源工程，
不预制不同季节的素材，不提前开发季节切换、昼夜时钟或天气系统。
未来扩展再评估植物状态、生活动作和光照，不能以整图套滤镜代替内容设计。

## 交付顺序与验收

作者要求先固定方案文档，再开始动手；现已同意进入制作。
依次验证全农村总构图、院落静态局部、局部动态样片、完整农村场景。
Codex 负责制作、自检与返工，作者负责阶段验收与调整，见 [制作与验收](production.md)。
总构图先确定八区的位置、体量、道路水系和过渡，不把八张独立插画拼成长卷。
院落—菜园—水渠是验证范围，至少验证一个居民与一只鸡的制作方法；
不因此要求全场同时出现大量同类活动。

| 阶段 | 通过条件 |
| --- | --- |
| 总构图 | 八区主要用途可辨，道路水系与地势连贯，三处生活节点与疏朗段协调，观察尺度可读 |
| 局部样片 | 符合唯一画风；人物接触与鸡的落脚可信，无明显滑步、闪烁、重影；动静与停顿自然 |
| 完整农村 | 八区关键内容与联系齐全，边界无明显拼接感，光照与比例统一，停下来仍有内容可看 |
| 运行与回退 | 检查电脑与真实手机的拖动、缩放、加载、暂停和反复进入；资源稳定，不因扩展持续累积内存；加载失败可重试，动态不可用时可静态观看 |

桌面接近 60 帧/秒、目标手机稳定 30 帧/秒和初步资源预算是待验证目标，
具体口径见 [架构](architecture.md)，尚无新场景实测结果。
优化先处理加载、分块、重复素材、无用帧和离屏活动；
不擅自以模糊原画或删除某区内容换取数字通过。
局部方法与成本可行后，沿相邻土地完成首期农村内容。
后续按另行确定的设计扩展小镇、城市等。
每次扩展都检查连接区域与整体动静关系。
工程通过不能替代作者对观看效果的验收，性能优化也不能擅自改变画风目标。

方案已可作为后续制作基线。文档定稿不表示总构图、动作、导出链路或性能已经验证，
当前概念总览已制作；它的尺寸不能当作正式长卷尺度，包含的居民不能直接复用为动作。
