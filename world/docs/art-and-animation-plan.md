## 背景与主体

1. 先设计完整农村的相对地形、用途、道路水系和疏密，再核对村落新布局。
   确定观察尺度与局部物件精度，图片尺寸不由旧坐标或单次生成上限倒推。
2. imagegen 辅助原画。明确唯一参考的作用、视角、光向、比例和邻接约束。
   用新增横向与纵向图块承载新增土地，保留共享地形，保持局部像素密度。
3. 生成后核对完整拼合、默认及最大视野，再决定发布；发现用途重复、
   通路断裂、季相不符或接缝问题时先返工，不仅修遮罩。
4. 正式背景不含需要活动的人物与动物；活动主体独立制作，
   仅拆出确有用途的前景遮挡，大多数静态器物留在背景。
5. 固定角色母稿，先静止放回场景检查尺度、笔触、接地与遮挡，再制作部件与动作。
   隐藏形体通过定向补画处理，同一角色的轮廓、服装和道具保持一致。

生成图片不是一次即合格的成品。
不逐帧重新生成整个角色，也不把多张独立姿态直接当作连续动画。
首期只做固定初夏上午，无声；冬季、夜晚不进入素材或系统清单。

## 动作制作与交付方案

Blender 可作为二维部件、固定相机与关键帧工具，保留可编辑工程、
部件来源、转轴、动作曲线与说明。贴图保留源稿笔触与色彩。
这是制作方案，尚无已验证的 Blender 到网页一键导出链路。

| 内容 | 待样片验证的交付方向 |
| --- | --- |
| 简单部件活动 | 复用贴图与有限关键帧数据 |
| 复杂接触、手脚与形变 | 补姿态或短透明序列帧 |
| 有实际用途的水车、风轮 | 轴心与部件连续运动 |
| 水纹、烟气与轻微环境变化 | 局部纹理或简单连续效果 |

选择以观感和资源成本为依据，不要求所有对象导完整序列帧。
只需有限片段播放器，不建设通用编辑器。
居民动作检查重心、手与工具接触、启停和停顿；鸡走停检查步幅、落脚、
位移与停止衔接。整图叠化、加帧或提高页面刷新率无法补救错误原稿与滑步。

## 源工程与验证

原始 PNG 与实际提示词留在源素材目录，发布副本按观看尺寸处理。
独立主体记录共同锚点、透明边界、帧时长、循环与必要步幅；
停顿复用静止姿态，同类动物可共享合格素材并错开节奏。

先验证一个居民、一只鸡及其院落预览，整体正常速度优先，
辅以慢速和最大尺度定位问题。同时检查下载、解码与真实设备成本。
工程、素材自检和作者观感验收分别记录，合格后扩展。
关键动作反复不合格时调整姿态或制作方式，不用“已生成”冒充完成。
