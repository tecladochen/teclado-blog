## 美术制作

首期只制作已定的 2025 年初夏晴天上午；八区内容与约 4–5 屏的观看范围
见 [农村场景方案](rural-scenes.md)。冬季和夜晚不进入本期素材清单。
保存可编辑源工程供后续评估复用，不提前制作其他季节或时段的版本。

1. 确定完整农庄总构图、默认视野、最大缩放和主体的屏幕尺寸。
   美术分辨率由实际观察尺度决定，不沿用旧世界坐标作为图片尺寸。
2. 用内置 imagegen，以唯一参考图制作连续背景和角色母稿。
   每次明确参考的作用、固定视角、光向、比例和必须保持的特征。
3. 先把角色静止地放回场景检查，统一色彩、轮廓、尺度与接地。
   角色独立漂亮但放回背景不协调时，继续调整原稿。
4. 制作动作需要的部件和姿态；可见部分复用同一母稿，
   隐藏形体通过定向编辑补全，合成静止姿态确认接缝与身份一致。

生成工具可以辅助原画与补图，不能保证一次生成即合格。
不逐帧重新生成整个角色，不将多张独立姿态自动当作连续动画。

## 动画制作与交付

Blender 可作为二维部件与关键帧制作工具：固定相机、共同转轴和角色部件，
通过关键姿势、运动曲线和必要补姿态制作有限的生活动作。
保留可编辑 `.blend` 工程、部件来源、转轴与动作说明。
贴图应保持源稿色彩与笔触，不因渲染照明擅自改变画风。

网页交付按对象和预算选择，而非一律导出完整序列帧：

| 内容 | 交付方向 |
| --- | --- |
| 简单部件活动 | 复用贴图与有限关键帧数据，网页更新位置、角度等 |
| 手脚、表情与接触关系复杂的片段 | 必要姿态或短透明序列帧 |
| 水车、风轮 | 复用部件，按轴心连续运动 |
| 水纹、烟气与轻微环境变化 | 局部纹理或简单连续效果 |

Blender 到网页关键帧的数据约定和导出链路尚未验证，不宣称一键可用。
首个样片应验证这条链路与观感；仅需有限片段播放器，不建设通用动画编辑器。
复杂片段也可从 Blender 导出透明 PNG，再按观看尺寸裁切、编码和打包。

工作动作先检查重心、手与物件接触、启动、停止和自然停顿。
短走检查步幅、落脚、位移、朝向和停止衔接。不能用整个人物图片叠化替代运动，
不能用增加帧数修复不一致的原稿或错误动作。出现纸片感时补姿态或调整交付方式。

## 资源与验收

源工程和发布资源分离。原始 PNG 保留作制作源，
发布素材按实际观看尺寸处理透明空白、共同锚点、帧时长、循环和步幅元数据。
动作先比较必要的采样率；停顿复用静止姿态，同种动物共享合格素材并错开节奏。

先交付一个居民、一只鸡及其放回院落的预览，提供正常速度、慢速和最大观看尺度。
同时检查整体节奏、下载与解码成本；观感通过后再扩展。
工程检查、素材检查和作者视觉验收分别记录。

制作能力包括原画迭代、部件整理、动作工程、导出、打包与验证。
精细手部、形变和接缝仍有风险；未完成样片前不承诺商业游戏级动画观感。
若关键片段反复不合格，明确反馈问题并调整制作方式，必要时讨论美术补画支持。
