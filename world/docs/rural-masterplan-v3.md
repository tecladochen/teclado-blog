## 道路网络与出入口

主乡路R1从G村口沿塘岸陆侧、果茶坡脚、畜养净前侧到C田园，再沿B公共院外侧转入A村巷。
乡路在B下侧、C西侧较下方、C东侧较上方、D前方、E坡脚和F/G陆侧改变位置，跟随入口与地势。
它只有一条主要串联线，不在三行重复铺平行宽路，也不围绕每个田块和树行修路。

| 路线 | 连接安排 |
| --- | --- |
| R0 对外 | 右边界 → G04装卸院；保留未来接续，不延伸制作小镇 |
| R2 竹桑支路 | C中东部主路节点 → 竹编/草菇/桑蚕共用工作前场；各门前短接 |
| R3 种养管理 | D主路节点 → 上侧共用管理线 → 羊、牛管理、储料、蛋鸡；一条短支到独立猪院 |
| R4 果茶管护 | E主路节点 → 梨茶共用入口 → 柑橘右支 → 蜂箱尽端维护 |
| R5 塘岸工作 | G侧主路 → 鱼塘陆侧工作岸、暂养 → 荷塘与鸭区的上侧管理岸；塘埂兼用，不每岸都修宽路 |
| R6 后场服务 | D右侧服务门、高侧窄线 → D06；牛鸡猪各后门与C材料周转接入，避开公共院、早餐、收奶和清洁分拣 |
| R7 生活步行 | A村巷 → B公共院 → 村务、店前与早餐 → C园艺前场；公共院内车行停止 |

每个场所入口已经标在示意数据中，门前短接属于可走作业/步行面，不都画成新土路。
X1为C/D田口附近主乡路跨引水的位置；田口和其他必要短过水设施按具体入口设置，不增加装饰桥群。

## 水系与生态、产业联系

W0从C东侧上边界进入，绕过旱地，经过X1到田间供水节点。
W1沿稻田较高边向C/D田口分水；W2沿田块低边向右，绕过全部养殖塘外侧，去右下游。
WF在田间进水前另分受控支线，主要采用地下或管理设施，分别到鱼塘、暂养、荷塘和鸭区。
各塘有独立取排口；鱼塘/暂养的陆侧管理点以及荷鸭服务侧处理位置，接管理出水线后去下游，不回流成农田入口。
生活、早餐、育苗准备、收奶与分拣清洁工作点由相应清洁水源供给；生活使用后收集，畜养液体经WD独立去D06。
示意中的虚线只表达地下或管理联系，正式画面无需把全部管线画出来。这里只有必要田渠和集中塘面，没有一条贯穿全村的装饰河。

| 联系 | 具体空间与周转方式 |
| --- | --- |
| 苗 → 菜/稻 | C02整理后经园艺前场到蔬菜入口或实际移栽田口 |
| 草料 → 牛羊 | D05靠圈舍，R3和田口短距离周转；不经村心 |
| 畜舍/草菇用后料 → 处理 → 适用田园养护 | 各服务侧到R6/D06，处理后按用途运回C/E；液体独立收集，不画作流入鱼塘的水渠 |
| 秸秆/适用加工副产物 → 菌菇/储料 | 从储备与G加工后场周转到C07/D05；六月稻田未收，使用储备材料 |
| 菜、苗、菌菇、茧、蛋及当期水产 → 分拣/外运 | R1/R5 → G02对应工作与储放 → G04 → R0；果茶荷藕以管护生长为主，不全部同时大丰收 |
