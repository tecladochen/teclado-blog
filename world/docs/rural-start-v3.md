- 左半部及后侧：完整缓坡的林地、树冠组、少量露土与草坡；自然边界落在这片山体，前方降到山脚，不出现天空或独立山景小卡。
- 右侧山脚：一户完整、普通的灰瓦浅灰米色墙住家，屋顶、墙脚、门窗和小檐下都在图内，房屋退离四边。避免像零售店般把整个前墙打开。
- 侧背院：有所属位置的洗涤点、少量晾晒、收好的农具和檐下收纳。门前只留实用尺度的小铺地，住宅和庭院向前方下一张继续。
- 家庭菜畦与宅旁树：在山脚边的少量完整菜床，生长叶菜和葱类有区别，一株宅旁树的完整形态可读；不是大果园或遮缝树林。
- 下边接点：门前步行面和相邻院地向中图继续，保留真实材料、影子和明确位置；主要建筑、树干、屋角不压图界。
