作者先要求从八区之前重新考虑底层空间，再认可完整二维方案；
随后认可统一原图、三图重叠和去重发布路线，明确要求写入文档并清除旧冲突。

| 项目 | 当前确认 | 被替代说法 |
| --- | --- | --- |
| 区域组织 | 保留八类内容，从地势、生活中心与生产通行关系组织土地 | 八区必须是八块固定区域，旧位置表继续约束新布局 |

| 原图 | 统一 2160×720 工作规格，场所通过不同数量图块展开 | 同期原图宽度不同，图片尺寸全部随时自由决定 |
| 纵向 | 固定三张、重叠 144、步长 576、有效高 1872 | 两图、整高单图或任意纵向数量继续列作本期备选 |
| 横向 | 重叠 216、步长 1944，列数按内容，不限制屏数 | 无固定重叠规格或固定世界长度 |
| 发布 | 离线修接选定唯一背景，最大 1024 有效块和每边 2 像素采样边缘 | 浏览器加载完整重叠原图再用复杂遮罩修接 |
| 支持范围 | 作者明确本期仅 PC，手机不展示；重点保证 PC 性能与体验 | 手机观看、触屏手感与真实手机性能成为本期验收要求 |
| 当前任务 | 将新规划、规格与 PC 验收定稿并提交进度，当前网页图片不动 | 自动开始生图、代码实施或重导 |
