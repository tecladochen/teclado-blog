# 需求变更记录

更新：2026-10-13。这里只保存影响当前要求的变更，完整有效需求以 [需求](redesign.md) 为准。
来源为作者在「排查会话报错原因」「重构世界地图布局」及本次整理中的直接反馈。
制作建议与生成结果不自动成为已确认需求。

| 变更 | 作者反馈与当前结论 | 已替代的条件 |
| --- | --- | --- |
| 长幅形式 | 《清明上河图》只强调长幅，内容按本项目独立设计；时代设为 2025 年 | 借用其历史内容、时代或叙事 |
| 首期范围 | 先完整做农村田园，其他地区大概规划、后续向右扩展；各区要素丰富多样 | 将作者举例的城市建筑写成必做清单 |
| 地域时段 | 作者接受江南丘陵与平原交界乡村、六月上旬晴天上午；先做一个季节，首期无声 | 未确认时代建议、提前做冬季与夜晚 |
| 长度 | “长度可以加不是非得限制4-5屏，按照内容来合理协调” | 约 4–5 屏、旧长宽比或等宽分段作为硬上限 |
| 左侧与纵向 | 村落重点完整展示，左侧自然收尾；上下内容明显增加 | 截断核心建筑、补空带或少量装饰就算完成 |
| 观看尺度 | 尺度由 Codex 重设，作者验收；全屏窗口固定，最小看全上下、最大受清晰度限制 | 旧截图尺度、固定 75% 下限、90% 默认或旧缩放倍率 |
| 新增空间 | 同尺寸整图展开更多土地会压缩细节，作者要求用新增局部图片体验更多空间 | 单张整高母稿承担更多土地、放大旧图冒充新增细节 |
| 全图组织 | 竹林应独立成区；上下院落与棚内内容要有区别，扩大空间应产生不同用途 | 在接缝横铺竹林、复制住宅与菜园棚群 |
| 重新设计 | “要重新设计，不要用之前的草图” | 沿用 v4 草图或其指定位置作为后续构图依据 |
| 当前任务 | 保持网页图片版本；清理试稿，只留当前必要图片；整理需求并提交进度 | 自动继续上次中断的生成与换图 |
| 简洁交互 | 作者此前明确去掉提示 UI、下拉框和多余按钮，专注画面 | 将后来预览页新增的控制写成最终需求 |
| 动态目的 | 让画面有活性、协调自然，不要求所有物体都动 | 完整劳动链、经营系统或各区持续劳动成为硬要求 |

八区内容方向经作者同意继续细化；具体物种、建筑数量、节点位置、物件像素标尺、
竹林在右上方的安排、Blender 交付方式和数值预算均属于 Codex 方案。
它们可以按质量核对调整，不写成作者逐项指定或验收通过。

当前 v3 是保留进度；原长卷 v1 曾获整体观感认可，并不等于所有细节与完整农村验收。
中断生成的后续稿没有完成交付，也没有作者验收；已按本次要求清理。
