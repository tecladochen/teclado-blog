背景保持 2025 年六月上旬晴天上午、虚构江南丘陵与平原交界乡村。
沿唯一参考的斜俯视、笔触与光照，无天空和地平线，首期无声。
横向长度随完整内容展开，纵向采用已确认的三图制作规格，形成 1872 像素有效高度。
三张原图的边界不对应三排场所。

- 后方是缓坡和较高干地，容纳竹木林地、果茶坡与局部畜养。
- 左侧中部是完整居住台地，形成乡村生活中心。
- 中部向前方展开耕地，是全场最宽、最开敞的部分。
- 右侧低地形成塘岸；旁侧干地上的公共农务场接对外道路，向未来小镇延伸。

## 村落与独立竹林

村落在最左侧，建筑整体退离世界边界。边界先经过疏树、坡脚和小径再进入住家，
使核心房屋、院门和侧背院完整，最左端有自然起点。
日常巷道略有转折，住宅错位，有不同屋型、朝向和院落开合，数量按真实用途细化。

主院承担备餐和家庭生活；邻宅偏向洗晾、休息或家用收纳。
树荫公共空地容纳邻里停留和通行，不能复制第二套主院、菜园和工具棚。
完整巷道与住家联系是村居内容，不能只增加几栋孤立房屋。

竹林位于村落右后方、越过住宅组团之后的一块独立坡地。
住宅与竹林之间留出可见坡脚空地和支路，竹林有明确林缘和范围，不横贯全幅。
阴凉处放菌菇管护；面向菜园和农路的明亮林缘放编作与修补。
两处的地面、材料和设施形态不同，不复制装满木材和篮子的棚。

## 八类内容的落位与用途差异

八类是完整农村的覆盖清单，可以交织在较大的生活片区中，不规定八块独立区域：

| 内容 | 新位置与主要用途 | 必须形成的差异 |
| --- | --- | --- |
| 村居生活 | 左侧居住台地，住家、巷道与公共树荫 | 各户有不同家务和生活痕迹，公共空地保留通行 |
| 菜园与育苗 | 村落右侧，到大田的过渡处 | 小菜畦服务餐桌，育苗点服务种植，集中组织 |
| 竹木、菌菇与编作 | 独立坡地与林缘 | 林内安静管护、林缘明亮制作修补，工作设施少而有用 |
| 果茶与蜂箱 | 竹林右侧延伸至中央后坡 | 果园为主，茶行局部出现，蜂箱靠边且可维护 |
| 稻田、旱豆与灌渠 | 中央最大平地向前展开 | 完整大田承担开阔感，旱豆在较高干地，田口设备集中 |
| 鱼塘、荷岸与鸭水 | 中右低地 | 主水面开敞，荷岸、鸭浅水、作业与安静停留分别安排 |
| 畜禽与饲草 | 塘岸后方的独立干地 | 小规模草地、畜舍、清理与收纳，与住宅和水体留缓冲 |
| 公共农务与村口 | 最右侧可达道路旁 | 分拣、共用器具、维修和对外联系集中，不在各区重复仓库 |

### 村居与菜园

生活细节按用途组织：备餐台有蔬菜、盆与篮；洗晾院有水管、晾晒与排水；
休息处有凳、茶杯或书；收纳处有少量常用工具。
电表、停放电动车等以低对比方式表达 2025 年，不需要各户重复完整设施清单。

集中菜园包含叶菜、葱蒜、小攀爬架、裸土畦与不同阶段的苗盘，畦间真实可走。
取水、工作面与篮筐收纳聚在入口，苗棚不遮住住家到大田的联系。
菜园到餐桌由短小径和物件位置表达，不强制制作全套送菜劳动链。

### 竹木林地与果茶坡

竹林形成一个主要密集体量，林缘渐开，内部有空隙和管护路径。
编作点有待修旧篮、半成品、竹片和少量工具；菌菇地有适合栽培方式的遮荫、材料与通道。
普通木堆不等于菌菇生产，具体品种与设施在制作清单中核对。

果树按坡势成组，留出树下通路，分筐位置靠坡脚支路；
少量茶行、蜂箱维护道提供与果树不同的纹理和用途。
具体果品仍属制作选择，统一初夏季相，不同时堆满不同成熟作物或露天制茶工厂。
篮筐修补服务果园、菜园与村口，菌菇连接住家与小规模外送。

### 大田、塘岸与畜养

大田保留少量完整大地块，田埂和渠线随地形，避免细碎网格和重复装饰。
绿稻以新栽或生长状态为主，旱豆在较高地，泵机、秧盘与农机集中于少量田口。
农机停在可达农路旁，桥宽与用途匹配，不把初夏画成满场秋收。

主塘保留大片开敞水面，荷叶聚在一角或浅岸，鸭有自己的休息和活动岸段。
网具、桶、收纳和作业平台集中在可达塘口，安静坐处面向另一段岸线。
鸡主要在院落，鸭主要在塘岸，小规模畜养在干地，避免所有动物聚在同一棚群。

畜舍设置草料、饮水、活动地、清理通路与独立收集点。
排水和粪污收集与塘渠隔开，空间缓冲不替代实际处理安排。
牲畜种类、数量按场所细化，不扩成大型牧场。

### 公共农务与出口

以紧凑的共同服务场所组织分拣、周转筐、存储、维修和包裹代收。
装卸停靠与公共通行分开，共用器具沿支路服务田口、果坡、塘口和畜舍。
初夏可有果品、苗盘、空篮与已有存粮，不能铺满正在秋收的谷物。
向右保留道路、地势和绿化接续，不提前制作小镇、城市或港口。

## 道路连接

农务主联系从村居外围接出，经菜园与林坡出口、田口、塘口作业点到公共农务场，
再向右延伸。路线随干地转折，不成为画面或图片接缝的一条水平分界线。

生活巷道较窄，直接连接院门、菜园与公共空地；运货路线绕过庭院。
竹林、果坡、畜舍有服务支路通到实际入口，塘岸安静步道与装卸空间拉开。
桥只出现在需要过水的位置，步行桥与农务道路桥按通行对象区分；
不在每个图块边界复制桥、井和棚。

## 水系连接

中央后坡溪沟从画面上边界接入，沿坡脚进入灌渠，向前方及右侧低地展开。
支渠服务稻田与菜园取水；鱼塘有受控引水与独立排口，主渠继续通下游。
住宅处在较高干地，生活排水另行组织；畜舍排水与粪污不直接流入塘渠。

用闸口、渠岸、田埂和台阶表达高低与入口，观者能读懂来水、分水和去向。
渠线不能为图片拼接方便穿过房屋或工作面，也不能反向跨坡硬接。

## 疏密与观看节奏

生活聚集 → 林缘过渡 → 田野展开 → 塘岸舒缓 → 村口再聚集。
大田获得最大连续面积，村落有通路与空院，竹林有主要密集体量与开敞林缘，
塘面形成安静留白，村口重新聚集但规模小于村落。
不固定开阔地占一半等面积比例，以完整场所和观看效果校准。

各段纵向用途不同：村居补生活纵深，林坡补地势和管护，
田野补完整田块与灌排，塘岸补水面和岸路，村口补后场和通行。
树影、田埂、林间空隙、草岸和使用痕迹属于正式内容，不用装饰填满所有空地。

默认从村居生活焦点进入并看全上下，横向拖动展开；放大后观察器具与主体。
动态候选优先院落生活、局部渠水、少量鸭活动与村口间歇整理，
具体节奏见 [动态设计](motion-direction.md)，不要求所有区域持续劳动。
