## 质量检查

- 先看定位、裁边、重叠和覆盖，区分组装错误与源图几何差异；发现可由定位解决的问题先调整定位。
- 看全场用途、通路、上下纵深和疏密，再逐处放大查看原图接缝和发布网格接边。
- 原画局部返工只修实际发现的位置，保留周边用途；修后再看完整场景，不以共享像素相同或算法成功证明视觉合格。
- 住宅、院墙、桥与通行点完整；水渠真实连通、主流不被误画成死端；器物和作物符合初夏与2025年。
- 色彩柔和协调，保持材料和形态可读，细节不靠密集过亮碎点；新增土地不压缩物件尺度。
- 网页检查PC默认全高、放大、拖动缩放和复位；后续多组性能另查弱网、后台、往返及资源持续累积。
- 动作按正常速度检查重心、接触、落脚、遮挡、启停，必要时慢放定位原因，叠化和加帧不能补救错误原稿。

代码修改运行 `pnpm lint` 与 `pnpm build`，有实际画面变化检查网页；工程检查不代替视觉和作者验收。
本期手机只检查入口隐藏与场景不初始化，不做手机渲染和性能优化。

## 生产与保存

`pnpm world:rural`根据当前素材recipe导出任意完整列数和按序修接，发布块按内容哈希命名，浏览器不下载工作PNG。
当前工具会重新计算编码，超长导出的计算缓存待实现；相同内容的发布URL保持稳定。
工作atlas和QA截取可写到项目外临时目录；原画、提示词、必要模板和修接记录保存在模块源目录。
每个实际阶段更新进度交接，续做读取最新记录，避免从废弃小样或旧暂停条件重启。
不主动Git提交、推送或外部发布，不改文章正文和任务外文件。
