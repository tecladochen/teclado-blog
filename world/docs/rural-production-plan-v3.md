# 乡村 v3 · 画风确认后的推进计划

2026-10-13，作者明确确认村心园艺 v3 与牛羊草料 v3 两张图作为本轮画风基础。
参考图中角色相似可接受，正式场景中的居民要多样化。本次交付为推进计划，未新生图、改网页或启动批量生产。
内容依据：[完整方案](farm-redesign-v3.md)、[32 个场所卡](rural-scene-cards-v3.md)、[内容审核](rural-content-audit-v3.md)。

## 1. 固定画风与人物规则

当前画风基础为 [村心园艺](../assets/art-direction/soft-village-style-study-v3.png) 与 [牛羊草料](../assets/art-direction/livestock-style-study-v3.png)。
统一柔和二维动画语言、斜俯视、建筑和人物比例、自然光向、克制高光与清楚轮廓。
柔和通过色彩和明暗表达，保持原生细节；不把全图模糊、连续生成式重绘或锐化当作统一画风的方法。
两图实际各为 1672×941，只是风格参照，不作为正式图块尺寸、坐标或完整场所布局。
原始院落参考保留为历史资料，不再作为本轮唯一基准。

先建立一份简短居民设定表，初步设计约 10–12 位有差异的主要居民，数量随实际场所调整，不代表单屏人数。
人物区分年龄、脸型、发型、身形、衣着色组、职业与动作；青年、中年和儿童形成主要生活活力，少量老年居民自然出现。
苗圃整理、店内交接、畜舍喂养、塘岸作业、维修与邻里交往分别有合适人物，不反复使用同一对年轻男女。
同一居民再次出现时保持身份一致；不同居民之间保留差异，衣着和造型仍属于同一画风。
公共区域可有小组互动，生产区域以少数具体作业者为主；每个主要视野有一个主要活动，其他人可以休息、观看或经过。
先做设定与布局，人物设定图和动作资产到样段阶段再制作。

## 2. 从内容方案细化为可生产的总平面

七片空间和 32 个场所继续完整保留，人文生活与产业综合排布。横向按场所增加宽度，不用固定总列数反推删减内容。
下一份产物是一张可读的总平面示意和对应场所落位表，标明建筑/田块/圈舍/塘面范围、入口、作业前场、后场与连接关系。
示意用于设计和生成控制，不作为放大后的美术背景。

| 空间 | 主要展开与三图纵深的用途 |
| --- | --- |
| A 生活村落 | 两组错位住家、侧背院、近宅菜地、兔养殖及共享停留；住宅和庭院跨上中下展开，不把所有生活压到中间 |
| B 公共村心 | 村务活动、树荫公共院、杂货投递、早餐与可转换临街前场；住家和服务后场提供纵深，主要乡路经过场所边侧 |
| C 园艺田作 | 园艺工作面、竹桑林下副业和主要田作分别有横向容量；后坡竹编/草菇/桑蚕，中部苗圃/蔬菜/花卉，前方稻田与旱地相互错位 |
| D 畜养草料 | 奶牛、羊、鸡、猪各有完整场所；高处圈舍与材料后场，中部活动地和管理，前方饲草/旱田/稻田；整片可占多列 |
| E 果茶坡 | 梨园、柑橘、茶地、蜂箱与管理前场，地势由后坡过渡至前方低地；果园和茶行保留整体量感 |
| F 水产塘岸 | 鱼塘与管理塘、荷藕、独立管理的鸭岸、岸上作业和装运；水面有完整形状，不能切成每行一条装饰河 |
| G 农务村口 | 碾米榨油、分拣仓储、维修木作、装卸农机；建筑、净作业面和服务后场按物流错位展开，并接对外道路 |

三张纵向图片是共同容纳一片土地的制作容量，不是三个等宽功能条带。
田块、院落、坡地和塘面可以跨行；道路不固定为每行一道横路。保留开敞田水、成片果茶和草料，与村心/生产院落的细节聚集形成节奏。

总平面同时落定既有 R0–R7 道路与 W0/W1/W2/WF/WL/WD 水线：
主乡路串联村口、生产区、公共村心和住家，短支路服务真实入口；后场运输避开公共院、收奶净区和净分拣面。
上游清洁供水分流至农田和独立管理塘系；田间排水从低侧绕过养殖水面，畜养和生活废水分别收集处理。
桥、田口和塘口只设在确有通行或管理需要的地方。
生态与产业联系落实为实际场所和往来：草料到圈舍、粪污到处理后场再按用途回田、秸秆到菌菇/材料利用、果蔬到分拣、粮油储备到加工、产品到村口装运和居民日常采购。
不把未经处理的污水或粪污直接画成进入鱼塘、菜地或公共生活的捷径。

总平面确定后，才覆盖候选图片网格：场所不随网格截断成独立拼盘。
建立跨边界的接点表，登记道路/水线/坡脚/建筑轮廓的出口位置、宽度、方向和相邻用途；具体像素由小样实际输出规格回填。

## 3. 小范围验证无重叠接续与真实观看尺度

首个样段选 B/C 交界，包含村心生活、园艺作业和前方田块。
它能同时检验屋顶与院边、树冠、入口、道路、作物和按总平面需要的田渠，不以纯草地掩盖难点，也不专为测试增加河流。

先制作上、中两行的 2×2 相邻有效图，检查全部横接、竖接及四图交点；通过后补前方一行，形成两列×三行的完整高度样段。
这一范围用于验证方法，不据此限制整村长度。角色也只在样段所需场所落位，不堆入全部居民。

正式单图可先试约 3:1 的横幅，但 2160×720 仅是候选请求，不能预写为工具已经支持的原生规格。
先核对实际返回幅面、原生清晰度和单位物件尺度，再锁定全部生产规格；不拉伸、放大旧参考图或裁掉重要内容去凑尺寸。
默认全高与合理放大都须看得清，不能为了全景容纳更多内容而缩小全部人物和工具。

相邻图以同一总平面、接点表、视觉约束和已选邻图为参照，有效内容按实际尺寸紧邻放置。
提示词与参考不能保证生成边界一致。发生接缝先排除页面坐标/采样问题；确属源画面不一致时，对失败接点尝试一次局部连接重画，并检查非目标区域清晰度。
仍不通过时停止扩量，调整生成单元或局部共用母稿方法，再用小样比较；不回到反复大量补丁与扩图并行的流程。
局部母稿不能用一张低细节整高全景放大来替代新增细节。

## 4. 原始 PNG 网页样段与一次集中验收

选用原始 PNG → 登记实际尺寸/路径/位置 → 直接预览 → 检查并修订。
保留原图、实际提示词和必要修接记录；运行副本按需原样复制，不走旧 WebP/Sharp 导出链路。
先只展示样段和必要邻图，沿用 PC 判断、相机、拖动缩放、复位和返回；不同时解码整片超长乡村，也不先重建复杂缓存系统。
代码改动运行 lint/build，实际页面检查默认全高、合理放大、移动跨边界与复位。

样段集中给作者验收：画风是否保持、尺度和细节是否合适、三图纵深是否有价值、道路水系是否节制、所有边界是否连续、居民差异与生活氛围是否自然。
逐一检查六张图的全部相邻边和两个四图交点，沿道路和水线追踪；局部编辑后复看整幅。
生成成功、坐标正确、工程检查通过和作者视觉认可分别记录，不以第一屏正确代替整段检查。
未经作者对样段效果确认，不开始大范围批量生产。

## 5. 按完整场所分批生产，随做随展示

建议依赖顺序为 A/B 村落公共生活 → C 园艺、竹桑林下与田作 → D 畜养草料 → E 果茶 → F 水产 → G 农务村口。
各批可以覆盖跨片连接和前后土地，不强制一批等于一列、一屏或一个产业。
F 在扩量前补足完整水面、塘岸和鸭区的风格与空间检查；畜养扩量前复核不同动物的比例和形态。

每批先细化全场落位与邻接，再生成选用图，直接接入原始 PNG 预览，检查完整场所、全部新增边界及与上一批的连续性。
下一批从实际选用且检查过的邻接边继续，不能从未选稿或修接前的边界续做。
阶段成果按完成且通过检查的场所记录，列出未解决位置；不把图像调用次数当作有效进度。
记录生成、返工和接入耗时，用实际瓶颈调整流程；未测量前不承诺整村固定小时数。

## 6. 主体、动态与最终优化

总平面阶段就登记人物/动物的落点、活动范围和遮挡。预定会动的主体与环境分开设计，避免全村画完后逐个擦掉烘焙人物。
样段阶段先验证少数独立人物和动物的静止接地、尺度、笔触及遮挡；这一检查不依赖完成全套动画。
批量环境与居民落位成立后，再分批补有限动作：有停顿的喂料/整理、少量短程经过、动物小幅活动等，不做经营系统或全村持续忙碌。
先验证一位人物和一种动物的正常速度动作、重心与接触，再复用已通过的方法；不把独立姿态或整图叠化当作动作完成。

整村联查内容覆盖、季相、产业与生活联系、道路水系、全部接点、角色多样性、动静节奏和清晰度。
作者确认完整效果后再做最终格式压缩、切块/缓存、加载预算与性能优化，并验证优化前后画面和清晰度一致。
随后检查 PC 首次进入、连续浏览、跨区往返、后台及资源释放。发布与 Git 提交/推送仍按作者届时授权执行。
