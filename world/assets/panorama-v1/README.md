## 接续与发布

[导出工具](../../scripts/prepare-panorama.ts)使用 Sharp 编码 WebP，保留源图尺寸、比例和颜色方向。
`pnpm world:panorama` 只更新本轮发布副本与 [运行清单](../../data/panorama-v1.json)，
不调用旧资产重建命令。发布目录为 `public/world/panorama-v1/`。

共享区域没有逐像素复制成功，不能认为提示词中的“保持不变”已经被工具严格满足。
网页采用 [边界计算](../../scripts/panorama-seams.ts)生成的矢量遮罩，
沿共享土地中相近的纹理选择边界，并手动保护育苗棚、编作棚、蜂箱与塘口平台的完整轮廓。
源 PNG 没有裁剪、重绘或拉伸；没有用透明度动画掩盖动作问题。
边界误差指标仅用于制作选择，不替代人工看图或作者验收。

| 发布项 | WebP 字节数 | 估算 RGBA 解码字节数 |

正常首视野只需西段，接近边界时加载邻段；浏览器、画布和 GPU 副本另有开销。
这些字节数是实际文件与像素计算，不能作为 PC 实机内存或帧率测量。
后续正式背景精度、角色和遮挡仍需在动态样片中验证。
