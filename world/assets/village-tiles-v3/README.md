## 网页与资源

新样片 `/world/`；原长卷 `/world/previous/`。全高缩小时，桌面两侧有中性色空余，
这是局部样片的有限宽度；后续向右增加场所会扩展实际土地，不拉宽现有图片填满窗口。
窄屏显示全上下的一段横向局部，左右可浏览。

[导出工具](../../scripts/prepare-village-tiles.ts)保留原生尺寸，编码 WebP 质量 90。
`pnpm world:village` 更新 [运行清单](../../data/village-tiles-v3.json) 和发布副本。
发布图合计 2,430,344 字节（约 2.32 MiB），三张 RGBA 理论合计 18,870,328 字节。
全高视野需要三张；局部按二维可见范围及邻近带加载，离开后卸载。
这些计算不包含浏览器和 GPU 副本，不是 PC 实机性能测量。

最大尺度为每个原生像素对应 0.75 CSS 像素，渲染密度最多 1.5；
每个源像素最多对应约 1.125 个渲染像素，作为本次近景清晰度的保守初始上限。
窗口变大不会提高此上限；缩小下限随窗口高度适配完整 1773 像素世界高度。
极高窗口若高度适配需要越过上限，优先保留清晰度并居中显示。
全高时物件在屏幕上自然变小，放大后仍保留原图局部细节，这是新增多图的用途。

新空间已按 [有效需求](../../docs/redesign.md)确认；本目录分块、坐标与尺寸仅描述当前 v3，
后续制作执行新定稿，不把这些旧参数当作可自由选择的新规格。
