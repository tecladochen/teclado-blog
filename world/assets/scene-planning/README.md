# 农村概念草图制作记录

两张图均按生成结果原样复制进工程，没有拉伸、裁切或重采样。
本次构图包含居民与动物，用于表达生活位置；正式素材需另制干净背景与独立主体。
页面目前不导入本目录，`public/world/` 未新增资源。
